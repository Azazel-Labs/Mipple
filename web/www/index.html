mipple WebAssembly demo Source on GitHub

mipple is a GPU texture encoder written in Rust: BC1, BC3, BC4, BC5 and BC7 with rate-distortion optimization, written to KTX2 with Zstd. RDO nudges each block toward bytes Zstd already saw, trading a little error for a smaller file. This page runs the real encoder, compiled to WebAssembly, on your machine. Pick a sample or drop your own image, move the sliders, and zoom in to see the blocks.
